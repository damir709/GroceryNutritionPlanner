# Iteration 1
This is the first iteration of our project. All files included in this folder are relevant for the project.

# Files

The files included are as follows:

main.py: The main source code for the project. It contains code for the Flask virtual framework web paths, and the functions to write to the SQLite database.

users.db: A very barebones users database file which stores a username and password for a client.

items.db: A database file populated with sample items
