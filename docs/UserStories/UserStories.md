# US-01 Create Account

As a shopper, I want to create an account so that I can use the system.

## Acceptance Criteria

- User can enter name
- User can enter email
- User can choose password
- User account is saved

# US-02 Browsing Items

As a shopper, I want to be able to browse items so that I can purchase them later.

## Acceptance Criteria

- User must be logged in to browse
- User account will have access to a database of items

# US-03 Create Basket

As a shopper, I want to have different baskets so that I can compare costs in a smarter way.

## Acceptance Criteria

- User must be logged in to access baskets
- User account will have 1 or more containers they can selectively add items to
- User baskets will display total sum of all item information
- If there is more than one basket, baskets will compare the sums of their info

# US-04 Item Information

As a shopper, I want to be able to view item nutritional information, so I can be more informed when I shop.

## Acceptance Criteria

- Items will have a name
- Items will have a brand
- Items will have a food group
- Items will have calories
- Items will have a purchase price
- Items will have a specific type
- Items will have a specific vendor location or store

# US-05 Favorite Items

As a shopper, I want to be able to favorite items I have viewed in the past, so that I can save or purchase them for a later date.

## Acceptance Criteria

- Users must be logged in to favorite items
- Items will have a "favorite" button
- Favorited items will be stored in each user account
- Items keep count of how many times they have been favorited.

# US-06 Price History

As a shopper, I want to be able to see recent prices on items, so that I know if the deal is right or not.

## Acceptance Criteria

- User must be logged in to see price histories
- Items will keep track of their last 5-10 sale prices
- Price increases and decreases will be highlighted on items

# US-07 Add Comments

As a shopper, I want to be able to leave comments on items so that people can read reviews and preferences.

## Acceptance Criteria

- Users must be logged in to leave comments
- Users will be able to leave a short comment
- User comments cannot contain special characters or unwanted phrases

# US-08 Vendor Verification

As a vendor, I want to verify myself on this platform, so shoppers know that my products are genuine.

## Acceptance Criteria

- Vendors will be able to create accounts
- Vendor accounts will be able to submit business and contact information for verification
- If vendor information is accurate, it will be displayed in their account that they are verified

# US-09 Edit Comments

As a vendor, I want to be able to edit or review comments on item that we sell, so that people are not misinformed.

## Acceptance Criteria

- Vendors must be verified to edit comments
- Vendor comments can be attached to items as well
- Vendors will be able to leave a short response to a comment
- Vendor comments cannot contain special characters or unwanted phrases

# US-10 Edit Items

As a vendor, I want to be able to edit item details, so that people are up to date on our current products.

## Acceptance Criteria

- Vendors must be verified to edit items
- Vendors will be able to adjust purchase prices, purchase locations, and other item information if the product has changed
