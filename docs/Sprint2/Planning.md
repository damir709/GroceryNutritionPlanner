# Sprint 2 Planning

## Sprint Goal

Build upon the current foundation, adding items and the ability to search for them as a user.

## Selected Product Backlog Tasks

- US-03 Create Basket
- US-04 Item Information
- US-05 Browsing Items

## Tasks and Subtasks

### US-03

- Implement a user basket that they can add searched items into
- Baskets have to compare item data fields directly


### US-04

- Implement a database of items
- Users must be logged in to access the item database

### US-05

- Add the ability to search for specific items in the database
- Users must be logged in to search


## Definition of Done

- Code committed
- Acceptance criteria met
- Database has no errors or exceptions
